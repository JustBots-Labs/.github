# Kelpgate

Malware scanning for the files your application accepts. One API call checks an upload or a URL against multiple engines and returns a verdict, so infected files never reach your storage.

| Project | What it is |
| --- | --- |
| [kelpgate-wordpress](https://github.com/KelpGate/kelpgate-wordpress) | Kelpgate Malware Scanner for WordPress: scans uploads and blocks infected files |
| [kelpgate-drupal](https://github.com/KelpGate/kelpgate-drupal) | Kelpgate Malware Scanner for Drupal: scans uploads through file validation |
| [kelpgate-node](https://github.com/KelpGate/kelpgate-node) | Kelpgate Client for Node.js (`@kelpgate/client`): library, CLI and Express middleware |
| [kelpgate-python](https://github.com/KelpGate/kelpgate-python) | Kelpgate Client for Python (`kelpgate-client`): sync and async library, CLI, FastAPI and Django helpers |

Every client uses the same names for the same things: see the [Kelpgate client standard](https://github.com/KelpGate/.github/blob/main/docs/client-standard.md).

Get started at [kelpgate.cloud](https://kelpgate.cloud) or open the [console](https://console.kelpgate.cloud).

The integrations and clients here are open source under GPL-2.0-or-later. The Kelpgate scanning service they connect to is a hosted commercial product and is not open source. See the [contributing guide](https://github.com/KelpGate/.github/blob/main/CONTRIBUTING.md), the [security policy](https://github.com/KelpGate/.github/blob/main/SECURITY.md) and [how to get help](https://github.com/KelpGate/.github/blob/main/SUPPORT.md).
