# Kelpgate

Malware scanning for the files your application accepts. One API call checks an upload or a URL against multiple engines and returns a verdict, so infected files never reach your storage.

| Project | What it is |
| --- | --- |
| [kelpgate-wordpress-plugin](https://github.com/KelpGate/kelpgate-wordpress-plugin) | Scans WordPress uploads and blocks infected files |
| [kelpgate-drupal-module](https://github.com/KelpGate/kelpgate-drupal-module) | Scans Drupal uploads through file validation |
| [kelpgate-node](https://github.com/KelpGate/kelpgate-node) | Node.js client, CLI and Express middleware (`@kelpgate/client`) |

Get started at [kelpgate.cloud](https://kelpgate.cloud) or open the [console](https://console.kelpgate.cloud).

The integrations and clients here are open source under GPL-2.0-or-later. The Kelpgate scanning service they connect to is a hosted commercial product and is not open source. See the [contributing guide](https://github.com/KelpGate/.github/blob/main/CONTRIBUTING.md), the [security policy](https://github.com/KelpGate/.github/blob/main/SECURITY.md) and [how to get help](https://github.com/KelpGate/.github/blob/main/SUPPORT.md).
